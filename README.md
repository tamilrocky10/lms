# Smart LMS — Streamlit

A simple Learning Management System built with Streamlit and SQLite.

## Features
- Separate Admin and Student login
- Admin dashboard
- Course creation and deletion
- User management
- Student course catalog
- Course enrollment
- Progress tracking
- SQLite database created automatically

## Demo credentials
- Admin: `admin` / `admin123`
- Student: `student` / `student123`

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

The SQLite database is created automatically on first launch.
